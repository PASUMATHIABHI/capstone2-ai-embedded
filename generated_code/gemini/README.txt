HOW TO USE IN WOKWI
1. Go to wokwi.com > New Project > Arduino Uno.
2. For each folder: open sketch.ino, diagram.json (and libraries.txt if present)
   in the Wokwi editor tabs and paste the contents of the matching files.
   (Or use the Wokwi upload/"Add file" option for each file.)
3. Press the green Start button.
Tasks: 1 LED blink, 2 DHT sensor, 3 Ultrasonic, 4 Servo, 5 LCD.
These are baseline files: verify wiring and behaviour yourself.
