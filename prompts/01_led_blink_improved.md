# Improved Prompt — Task 1: LED Blink

**Prompt:**
> Role: You are an embedded systems instructor. Board: Arduino Uno. Task: Blink an external LED once per second using digital pin D8 through a 220 Ω current-limiting resistor to GND. Constraints: Use only built-in Arduino functions (no external libraries). Include a wiring description in comments. Output must be a single `sketch.ino` file and a matching Wokwi `diagram.json` with parts `wokwi-arduino-uno`, `wokwi-resistor` (220 Ω), `wokwi-led` (red), and correct connections. Do not use the built-in LED on D13.
